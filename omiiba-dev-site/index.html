What makes it different

More than a renamed firmware build

Omiiba3DS keeps the trusted Luma3DS foundation, then adds a practical layer for day-to-day use: guided setup, launch shortcuts, readable status checks, OTA update setup, GBA display presets, bundled DS setup help, DS widescreen management, and VC patch guidance.

Omiiba Boot Hub

Holding SELECT opens Omiiba Boot Hub first. The classic advanced settings stay available, but the main flow is easier to understand.

Setup wizard

A first-run walkthrough for splash behavior, brightness, game patching, external FIRMs/modules, and GodMode9 placement.

GBA Labs

Launch bundled open_agb_firm, write safe display presets, check the GBA database, and keep deeper AGB_FIRM filter work clearly marked as research.

Bundled DS Labs

The release includes TWiLight Menu++ files, checks the setup, creates the recommended DS ROM folder, and points users to the CIA install step.

DS Widescreen Labs

Toggle the TWL external filter setting, check the widescreen compatibility list, create setup notes, and prepare DS widescreen helper folders.

OTA through Universal-Updater

The release bundles Omiiba Updater plus a UniStore so users can install the latest boot.firm over Wi-Fi from Homebrew Launcher or Universal-Updater.

VC Patch Helper

Create the Omiiba title-patching template, check game patching status, and document LayeredFS, IPS, BPS, locale, and RomFS patch layouts.

Payload manager

Launch .firm payloads, check available payloads, view hotkey naming help, and create non-destructive hotkey copies.

GodMode9 handoff

Omiiba does not pretend to replace GodMode9. It gives you clean shortcuts and scripts while keeping risky tools in the right app.

Omiiba Boot Hub

The new front door for your 3DS

The old SELECT configuration screen still exists, but Omiiba Boot Hub now sits in front of it. From there you can boot normally, save changes, launch payloads, run diagnostics, apply profiles, or enter advanced settings when you really need them.

Install

Install from the release archive

Omiiba3DS is installed like a normal boot.firm based custom firmware release. Download the archive, extract it to the root of the SD card, and merge the included folders when prompted.

  1. Use a Nintendo 3DS system that already has boot9strap installed.
  2. Extract Omiiba3DS-v1.4.8.zip directly to the SD card root.
  3. Hold SELECT while booting to open Omiiba Boot Hub.
  4. For DS games, install SD:/TWiLight Menu.cia with FBI after extraction.
