Omiiba3DS GBA Labs notes
========================

Stable path: open_agb_firm
--------------------------

The Omiiba3DS release zip bundles the official open_agb_firm payload here:

  SD:/omiiba/payloads/open_agb_firm.firm

It also bundles open_agb_firm's GBA database here:

  SD:/3ds/open_agb_firm/gba_db.bin

Then boot while holding SELECT and open:

  Omiiba Boot Hub -> GBA Labs -> Start open_agb_firm

Omiiba3DS launches the payload and can write display presets to:

  SD:/3ds/open_agb_firm/config.ini

The preset menu is here:

  Omiiba Boot Hub -> GBA Labs -> Display presets

Available presets:

- Original 1:1: no scaling, no color correction.
- Balanced matrix: matrix scaler with the GBA color profile.
- Soft bilinear: bilinear scaler with SP101-style colors.
- GBA color: lower saturation/brightness bias for older games.
- SP101 bright: brighter AGS-101-style profile.
- Vivid emulator: more saturated VBA-style profile.
- Battery saver: lower backlight and no color processing.
- Reset open_agb_firm config: conservative fallback defaults.

The preset writer only changes SD:/3ds/open_agb_firm/config.ini. GBA ROM
selection, save handling and gameplay remain open_agb_firm features.
Credits, licenses and source links are included in:

  SD:/THIRD_PARTY/open_agb_firm/

AGB_FIRM research status
------------------------

Virtual Console GBA injects use Nintendo's AGB_FIRM legacy mode. In that mode,
the normal 3DS system environment is not available in the same way as NATIVE_FIRM,
so Rosalina-style live screen filters should not be expected to work during
GBA gameplay.

Current Omiiba3DS research findings:

- TWL_FIRM has an existing TwlBg upscaling filter replacement path.
- AGB_FIRM currently only has a known boot-splash patch in this codebase.
- The next real VC-inject research step is finding AgbBg/display-driver
  constants or tables, not trying to apply Rosalina live filters.
- Scaling/filter changes for VC injects need a verified AGB_FIRM display-driver
  patch point before they can be safely exposed as real features.
- Color/gamma presets for VC injects need the same kind of verified pre-launch
  or FIRM-level patch path.

For now, the GBA Labs scaling and color entries are intentionally marked as
research. They document the direction without pretending the experimental
patches are already stable.
