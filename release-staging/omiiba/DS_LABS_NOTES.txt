Omiiba3DS DS Labs notes
=======================

Bundled path: TWiLight Menu++ / nds-bootstrap
---------------------------------------------

Omiiba3DS bundles the official TWiLight Menu++ 3DS release for convenience.
For DS games from SD, use the community-standard TWiLight Menu++ and
nds-bootstrap stack.

Bundled files:

  SD:/TWiLight Menu.cia
  SD:/BOOT.NDS
  SD:/_nds/
  SD:/roms/

Install SD:/TWiLight Menu.cia with FBI or your preferred title installer to
launch TWiLight Menu++ from HOME Menu.

Recommended DS ROM folder:

  SD:/roms/nds/

Common TWiLight/nds-bootstrap paths checked by Omiiba diagnostics:

  SD:/TWiLight Menu.cia
  SD:/BOOT.NDS
  SD:/_nds/
  SD:/_nds/TWiLightMenu/
  SD:/_nds/nds-bootstrap-release.nds
  SD:/_nds/nds-bootstrap.nds
  SD:/_nds/TWiLightMenu/extras/usrcheat.dat

TWL filter status
-----------------

Omiiba3DS already has a TWL_FIRM filter hook inherited from Luma3DS. When the
Advanced setting "Enable DSi external filter" is enabled, Omiiba tries to patch
TwlBg with:

  SD:/omiiba/twl_upscaling_filter.bin

This affects DS(i)/TWL software, not GBA/open_agb_firm. DS Labs only checks and
documents this path; it does not generate custom filter binaries yet.

Safety
------

DS Labs diagnostics are read-only. The "Create DS folders" option only creates
or verifies SD:/roms/ and SD:/roms/nds/. Installing the bundled CIA is a
separate user action performed in FBI or another title installer.
