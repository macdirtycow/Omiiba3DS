# 3ds_pm
Open source replacement of the Arm11 PM system module.
This is licensed under the MIT license.

# Usage
To run this system module, use a recent release or commit of [Omiiba3DS](https://github.com/OmiibaTeam/Omiiba3DS/), build this project and copy the generated CXI file to `/omiiba/sysmodules/pm.cxi`.
